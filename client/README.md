# Mission Control frontend

React 18, Vite, React Router 7, and Arwes Bleeps sound effects.

From this directory:

- `npm start` — development server on port 3000, proxying `/api` to port 8000.
- `npm run build` — production files in `build`.
- `npm run preview` — preview the production build.
- `npm test` — Jest and Testing Library tests.
- `npm run test:watch` — Jest watch mode.

See the [project README](../README.md) for installation, linting, Cypress,
audio compatibility, environment configuration, and deployment instructions.
